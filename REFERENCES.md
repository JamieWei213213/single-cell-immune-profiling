# Sources, attribution, and evidence

Checked October 20, 2026. Official documentation is mutable; the notebook pins its computational versions and records the actual installed environment. No website text or tutorial code is reproduced wholesale.

1. **Dataset provider and terms:** 10x Genomics, [3k PBMCs from a Healthy Donor](https://www.10xgenomics.com/datasets/3-k-pbm-cs-from-a-healthy-donor-1-standard-1-1-0). Source for sample/donor count, called-cell count, Cell Ranger version, publication date, and explicit CC BY 4.0 notice. [License](https://creativecommons.org/licenses/by/4.0/). Derived exports retain attribution and identify processing changes.
2. **Official raw loader:** [scanpy.datasets.pbmc3k](https://scanpy.readthedocs.io/en/stable/generated/scanpy.datasets.pbmc3k.html). Documents download, dimensions, raw `.h5ad` cache, and construction from the 10x filtered gene-barcode matrix. Upstream barcode calling is distinguished from normalization/clustering.
3. **Reference workflow:** [Scanpy PBMC3k preprocessing and clustering, legacy workflow](https://scanpy.readthedocs.io/en/stable/tutorials/basics/clustering-2017.html). This project's broad pipeline is an adaptation, not an exact result replication. The page was identified in current official documentation; repeated detailed retrievals encountered rate limiting. Do not claim detailed line-by-line replication.
4. **Biological marker reference and visualization caveats:** Satija Lab, [Seurat guided PBMC3k tutorial](https://satijalab.org/seurat/articles/pbmc3k_tutorial.html). Primary workflow documentation supplies CD3D/CD3E T-cell evidence; MS4A1/CD79A B-cell evidence; CD14/LYZ and FCGR3A/MS4A7 myeloid evidence; NKG7/GNLY cytotoxic/NK evidence; FCER1A/CST3 dendritic evidence; PPBP/PF4 platelet-associated evidence. Marker panels are interpreted jointly, not as universal one-gene identity tests. Cluster IDs from that tutorial are not copied into our annotations.
5. **Leiden API:** [scanpy.tl.leiden](https://scanpy.readthedocs.io/en/stable/generated/scanpy.tl.leiden.html). Documents graph prerequisite, resolution, random seed, backend, and iteration options. The project uses explicit backend/settings for reproducibility.
6. **Marker-ranking API:** [scanpy.tl.rank_genes_groups](https://scanpy.readthedocs.io/en/stable/generated/scanpy.tl.rank_genes_groups.html). Specifies logarithmized input, cluster-versus-rest behavior, tie correction, p-value adjustment, detection fractions, and warns about sample-level inference. We explicitly use `.X`, not `.raw`, for the unscaled log expression.
7. **Installation:** [Scanpy installation](https://scanpy.readthedocs.io/en/1.11.x/installation.html), [Scanpy 1.11.5 release](https://pypi.org/project/scanpy/1.11.5/), [igraph 0.11.9](https://pypi.org/project/igraph/0.11.9/), [leidenalg 0.10.2](https://pypi.org/project/leidenalg/0.10.2/). The selected Scanpy release is intentionally pinned, not advertised as latest. Its PyPI metadata lists BSD-3-Clause and Python >=3.10; the project's full stack is intentionally limited to Python 3.11/3.12. Release availability is not a substitute for end-to-end installation testing.
8. **Software paper:** Wolf FA, Angerer P, Theis FJ (2018). SCANPY: large-scale single-cell gene expression data analysis. Genome Biology 19, 15. [doi:10.1186/s13059-017-1382-0](https://doi.org/10.1186/s13059-017-1382-0).

## Attribution to include with shared results

Data: 10x Genomics, 3k PBMCs from a Healthy Donor (2016), Cell Ranger 1.1.0, CC BY 4.0; source and license links above. Changes: cell/gene quality filtering, normalization, feature selection, dimensionality reduction, graph construction, clustering, visualization, exploratory marker ranking, and provisional annotations. Workflow adapted from Scanpy's PBMC3k reference, with marker interpretation informed by the Seurat PBMC3k reference. This project adds explicit audit, uncertainty, and fixed-graph resolution sensitivity analysis.
